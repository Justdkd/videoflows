# VideoFlows 风格选择

## 概览

每期先定风格再剪。顺序固定：**先问用户想要什么 → 出 3–5 个明显不同的方向（效果图）→ 用户挑（G3）→ 出 7–10 秒样片 → 用户点头（G4）→ 写 `style/style.md` 交给剪辑。**

## 步骤

1. **先问**，一次问完，用户可以只答一部分：
   - 这期想要什么感觉？有没有喜欢的参考（视频链接、截图、账号）？
   - 有没有不想要的（颜色、风格、上期用过的）？
   - 要不要从你的私人风格库里挑一个用过的？（档案里有风格库才问）
   用户说「你看着办」，就按选题和档案里的风格底线自己定方向，照样出几版。用户明说「直接做一版」，就只出一版，跳过 G3，G4 照停。
2. **出 3–5 个方向**，彼此要明显不同，不是同一个模板换颜色。每个方向写清四样：
   - 制作方式（例如纸片拼贴、黏土 3D、等距小场景、动态排版、实拍加信息卡）
   - 版式（人在哪、信息卡在哪、字幕在哪）
   - 配色（列出主色值）
   - 画面架构（全片反复出现的「舞台」或「框」，章节怎么切换）
   每个方向出一张效果图（16:9 或 9:16，按成片方向），用手上有的工具做：HyperFrames、Remotion、three.js、Blender、生成图都行。出镜的地方画占位框，标「真人」。
3. **停在 G3**：把效果图并排给用户，每个一句话说它适合这期的什么。用户挑一个或说要混搭。
4. **用户给意见**：先用一两句复述「打算改成什么」，用户说对了再改。不要一收到意见就回去出新版。
5. **样片**：按选中的方向做 7–10 秒、720p 的样片，挑这期最有代表性的一段口播，出镜处用占位框，带上字幕样式、一个转场和一个信息卡。**停在 G4**，用户点头才算定。
6. **写 `style/style.md`**：制作方式、版式坐标、色值、字体、字幕样式、转场、每类信息卡的做法、出处。卡上 `notes` 记一条「风格定了：<名字>」。用户有私人风格库的，问一句要不要收进去（写到他自己的库，不写进本仓库）。

## 规矩

- 借别人的风格，只借制作方式；版式、配色、画面架构都要换，不能和别人的视频撞。只换颜色不算改。视频里给出处。
- 不用 AI 工具产品自带的品牌配色当主色。
- 水准下限：档案里写了「下限是哪一期」，出方向前先拿它当尺子比一遍。
- 档案里的风格底线（例如「小部件要立体精致，不要简笔平面」「动效要丰富」）每个方向都要过。
- 不用生成视频模型冒充实拍；出现真人的画面只用用户自己的素材。

## 常见错误

| 错 | 对 |
|---|---|
| 没问就直接出一版 | 先问，再出 3–5 个方向（用户明说只要一版除外） |
| 几个方向只是换色 | 制作方式、版式、配色、架构至少换三样 |
| 用户说「再精致点」就重做 | 先复述打算怎么改，对齐再动手 |
| 样片直接用 1080p 全片 | 7–10 秒、720p，够判断就行 |
