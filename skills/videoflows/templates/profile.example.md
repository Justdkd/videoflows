# VideoFlows 私人档案（示例）

> 复制到 `~/.videoflows/profile.md`（或 `VIDEOFLOWS_PROFILE` 指向的位置）再改。这个文件只放在你自己电脑上，不要提交进任何公开仓库。

## 账号

- 定位：一句话写你做什么内容，例如「AI 实际用法分享 + 健身」
- 主平台：抖音 / 小红书 / B 站 / YouTube / X（按你的实际写）
- 各平台语言：例如 YouTube、X 用英文
- 节奏：每周几条

## 工作目录

- workspace：`~/Videos/videoflows-work`（每期一个子目录）
- 看板仓库：`~/code/videoflows`
- 剪映草稿根目录：macOS 一般是 `~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`
- 私人风格库（可空）：你自己存定稿风格的目录或仓库

## 口吻（写稿用）

- 开头习惯：
- 列举习惯：例如「第一个是……第二个是……」
- 常用口语词：
- 别写的句式：
- 结尾习惯：
- 可以从两三期自己录过的稿子里总结出来，`videoflows-script` 第 1 步会帮你做。

## 红线

- 不提的事：
- 出镜：谁可以出镜、谁不出镜
- 职业 / 雇主怎么说：
- 引流：口播里能不能放链接

## 制作偏好

- 讲解类横屏还是竖屏：
- 成片规格：例如 4K 横屏 3840×2160，竖屏 2160×3840，30fps
- 字幕：位置、每屏字数
- 风格底线：例如「动效要丰富、小部件要立体」「不用某某配色」

## 发布和数据

- 发布时间偏好：
- DOU+ 预算上限（只做建议，下单永远是你自己）：
- 数据怎么读：例如「用我的 Chrome 只读后台，我说电脑开着再读」
