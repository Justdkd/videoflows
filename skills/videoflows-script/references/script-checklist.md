# 口播稿写法和自查

通用规则。私人档案里的「口吻」优先于这里。

## 一、写法

1. 开头先说自己做了什么、结果是什么；第一句里有「我」、有具体产品或数字。也可以用一个直接的问题开头，不用哲学式提问，不用假前提。
2. 观点前面带上「我」：「我觉得」「在我看来」。
3. 几件事并列时说「第一个是……第二个是……」。
4. 讲经过照时间顺序，一个动作接一个动作，句子短，主语是「我」和「它」。
5. 缺点和限制直接说，不先夸后贬。
6. 产品名、技术词照原文说，字幕里括号配中文，口播里不展开。
7. 计划写「会」，不写成已经做了。
8. 结尾落在自己的做法或观众能做的一个动作上；不喊关注，不承诺没定的事。
9. 借来的方法说一句出处，或屏幕上贴来源。

## 二、交稿前逐句自查

1. 读出来像不像跟朋友讲事？
2. 有没有「不是……是……」「问题不在……在……」「缺的不是……是……」这类对仗句？
3. 有没有路标句：「先说……」「接下来讲……」「最后是……」「X 的三个习惯。」？
4. 有没有自问自答，或冒号后面揭晓答案？
5. 观点前有没有「我」？
6. 列举是不是「第一个是……」？
7. 段尾有没有总结式金句？有就标出来，留给作者决定。
8. 每个事实都有出处吗？没有的标【待确认】。
9. 开头和这期选题合不合？作者给了原句的有没有原样保留？
10. 英文术语字幕里有没有配中文？

## 三、别写 → 改成（例子）

| 别写 | 改成 |
|---|---|
| 先说怎么分。我建议从三个开始。 | 我一般是开三个，一个只管一件事。 |
| 缺的不是时间，是人手。 | 我一个人做，事一多就干不完。 |
| 哪一步别交给 AI？发出去的那一下。 | 有一步我不会交给 AI，就是最后点发送。 |
| 先别急着让它剪，先把要求写清楚。 | 我现在都是先把要求写清楚，再让它剪。 |
