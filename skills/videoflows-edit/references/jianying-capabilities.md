| agent 能在草稿里做（已验证） | 待验证 | 没有接口，要用户在剪映里手动 |
|---|---|---|
| 会员 BGM（需剪映会员） | 文字循环动画 | 人物特效 |
| 会员音效（需剪映会员） | 关键帧（注意时间是片段内的相对偏移） | 蒙版 |
| 转场（例：倾斜拉开） | 更多花字样式 | 贴纸 |
| 画面特效（例：放大镜视角、旋转圆球） | 断网时用联网素材 | 调色 |

## 已知的坑

- 素材不是 H.264 / yuv420p 时，上游代码会转成 1920×1080 加黑边、30fps，竖屏会被压扁。先自己转码并保持原分辨率。
- 剪映打开明文草稿后可能把它存成加密格式：生成新草稿不受影响，读取或改剪映存过的草稿会失败。
- 视频蒙版在新版剪映上可能被丢掉。
- 同一类型的多条轨道，图层顺序不一定稳定，生成后在剪映里看一眼。
