# VideoFlows 发布

## 概览

做好封面和各平台文案，在用户自己的浏览器里把上传页面填好。**用哪版封面用户挑（G6）；点「发布」永远是用户自己（G7）。**

## 步骤

1. **读输入**：终稿、`research.md`（出处）、私人档案的平台、语言和红线。
2. **封面**：每个平台按它的比例出 2–3 版（例如 3:4 竖、4:3 横、16:9 横），封面字 4–8 个字，和标题不重复说同一句。需要英文的平台出英文版。**停在 G6** 让用户挑。
3. **`publish.md`**，每个平台一节：
   - 标题（按平台字数），作品描述 / 简介，标签，章节时间（长视频平台），出处列表（借来的方法、引用的数据，带链接；不允许放链接的平台只写名字）。
   - 评论区的一个口子：一句真实的问题，引观众留言。
   - 标签热度：在用户浏览器里用平台的搜索框搜一下各标签的播放量（只读），挑有量的；没查的写明「没查」。
   - 发布时间建议：按这个账号过去的数据，没有就按平台常见高峰，写明依据。
   - 用了 AI 生成画面或声音的，提醒勾选平台的「AI 生成」标注。
4. **填表**（可选，只在用户当次明确让你填时做）：在用户自己的浏览器里打开各平台上传页，把标题、简介、标签、分区、定时等字段填好。视频文件和封面文件由用户自己选（agent 碰不到用户电脑上的文件选择框时，告诉他选哪个文件）。**停在 G7**：填好后告诉用户「填好了，你检查后点发布」，agent 不点发布、不点付费推广。
5. **记录**：用户说发了，按仓库 `AGENTS.md` 5.5 给卡加发布记录（链接、发布时间、标题），卡推到 `data`。

## 规矩

- 不放引流链接到不允许的平台；红线里的话题不进标题和简介。
- 只读、只填：不改账号设置、不授权第三方、不开通任何付费功能。
- 各平台文案按平台写，不是同一段复制五遍。

## 常见错误

| 错 | 对 |
|---|---|
| 替用户点了发布 | 填好后停下，用户自己点 |
| 标签凭感觉写 | 在平台里查过量再定，没查写明 |
| 出处只放在一个平台 | 每个平台都给出处，形式按平台规矩 |
